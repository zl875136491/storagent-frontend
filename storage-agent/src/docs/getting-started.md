Storage Agent（跨站点对象存储管理与接入平台）帮助你完成区域与 MinIO 拓扑运维，并为业务应用发放 **APIKey**，使业务侧能通过统一文件接口上传/下载对象。

## 你需要什么

| 角色 | 目标 |
|------|------|
| 平台管理员 | 配置区域、MinIO、授权应用；必要时编辑跨站点复制拓扑 |
| 业务接入方 | 创建应用 → 获授权 → 领取 APIKey → 调用文件接口或嵌入组件 |

## 5 分钟上手路径

### 管理员侧（控制台）

1. **登录**控制台。
2. **区域管理**：创建区域（名称 + 简称）。
3. **MinIO 服务管理**：登记各区域 MinIO 实例（连接信息、权重等）。
4. **应用管理**：对业务提交的应用执行「授权」（会在各站点准备应用桶与复制等）。
5. （可选）**存储桶管理**：查看/编辑跨站点复制拓扑（编辑仅管理员）。
6. （可选）**角色管理**：将其他账号设为管理员，分担运维权限。

### 业务接入侧（控制台）

1. **应用管理** → 新建应用（APPID、显示名称、描述）。
2. 等待管理员完成「授权」。
3. **APIKey 管理** → 选择已授权应用 → 新建 APIKey（**明文仅展示一次**）。
4. 将 APIKey 与可达的 Storagent **API 基址**交给开发同学。
5. 按文档继续：
   - [功能接口引导](?doc=api-guide)：自行对接 HTTP 接口
   - [功能组件引导](?doc=file-components)：试用/拷贝上传下载 Demo

## 鉴权约定（务必记住）

- 控制台登录接口使用 JWT（`Authorization: Bearer <access_token>`）。
- **业务文件接口不使用 JWT**，请使用请求头：

```http
x-api-key: <你的 APIKey>
```

错误示例（不要用）：`Authorization: Bearer <APIKey>`。
